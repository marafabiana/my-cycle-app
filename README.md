# MyCycle

A simple web app to track menstrual cycles, built with Next.js, TypeScript, Tailwind CSS, Shadcn UI, NextAuth, Prisma, and SQLite.

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Shadcn UI
- Prisma ORM
- SQLite
- NextAuth (Credentials)

## How to Run the Project Locally

1. **Clone the repository**

```bash
git clone https://github.com/marafabiana/my-cycle-app
cd my-cycle-app
```
2. **Install dependencies**
```bash
npm install
```

4. **Set up the databases**
```bash
npx prisma migrate dev --name init
```

6. **Start the development server**
```bash
npm run dev
```
